Câu hỏi & Hướng dẫn sử dụng

Mọi thắc mắc về quy trình thanh toán, tải file và cách thức cài đặt tài nguyên lên phần mềm dựng phim sẽ được giải đáp tại đây.

⚙️ Hướng dẫn cài đặt tài nguyên

1. Cách cài đặt LUTs vào DaVinci Resolve
Giải nén file tải về, mở DaVinci Resolve lên, vào phần Settings > Color > Open LUT Folder. Sau đó copy thư mục chứa file `.cube` vào đây, bấm nút Update Lists là xong. Hoặc bạn có thể kéo thả trực tiếp file LUT vào khung Node ở Color Page.
2. Cách sử dụng Transition và Sound FX trong Premiere Pro
Sau khi tải về, mở Premiere Pro, vào mục Essential Graphics để import các template MOGRT hoặc kéo trực tiếp các file project mẫu vào bảng Project Panel để bắt đầu cắt ghép.
